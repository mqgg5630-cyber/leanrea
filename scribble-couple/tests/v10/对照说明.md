# 第9轮 · 第三列是怎么来的 + 四条路线实测

## 结论

**第六轮第三列 = 拿第二列原画当 target 的 1:1 复刻。** 它像第二列是这个原因，
不是从第一列（原片）推出来的。所以：

- 只要**这一对的原画在场**（图 1 = 原画 target，图 2 = 原片只核对细节），
  用第六轮那段提示词可以**稳定复现第三列水平**——v10 五对全部回到这个水平。
- **只给照片**时，做得到「同一位画手画的另一对」，做不到「同一张画」：
  线细、脸圆、眼大、太干净，抄得到画了什么，抄不到怎么画的。

## 逐条实测（五对 A–E）

| 路线 | 输入 | 结果 |
|---|---|---|
| ③ 第六轮第三列 | 原画 target + 原片核对 | 交付版，几乎同纸（基准） |
| ⑤ 逐字复用第六轮提示词 | 同上 | 五对全部复现第三列水平；个别多出杂色笔触 |
| ④ 只用照片 + 风格锚 | 原片 + artwork-X | 内容对、手不对：线细、脸圆、眼大、太干净 → **明显不像** |
| 丙 两段 self-trace | 只用原片，草图再复刻加粗 | 更糙，但自己发明条纹背景、改道具 → **失真** |

## 处理办法（写进 SKILL.md 的口径）

1. 有原画 → 图 1 = 原画 target，图 2 = 原片核对细节，用第六轮那段逐字提示词。这是唯一达标路径。
2. 只有照片 → 只能做「同手不同画」，用附录 A 的 CRAYON HAND 约束，别当交付。
3. 二次复刻加粗 → 不当补救手段（换糙感，丢构图）。
