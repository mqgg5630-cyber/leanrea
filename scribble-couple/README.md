# scribble-couple · 蜡笔涂鸦情侣头像（签名 sdldyh）v2

> 复刻用户发来的那版「抖音手绘情侣头像」：纯白纸、**两遍**抖断的黑蜡笔线、方宽脸、黑色圆角矩形眼、整块黑刘海、彩铅斜排线露白、每侧三四道腮红，右下角手写 `sdldyh`。
> 一个 `SKILL.md` + 风格拆解 + 可复制提示词 + **10 张用用户原片复刻的成品**，不依赖任何第三方服务。

## 这一版为什么重做

v1 交付后用户的判断是：**「你复刻的一点都不像，没我上传的好看。」**

把 v1 成品和用户样张并排缩小看，问题一眼就出来了：

| v1 做错的事 | 后果 | v2 的修法 |
|---|---|---|
| 单层、等宽、顺滑的线 | 像矢量贴纸 | **每条轮廓画两遍**，抖、断、末端出头 5–10px |
| 圆脸 + 尖下巴 | 变成「精致二次元」 | **宽、平、略方**，下颌几乎垂直，下巴钝平 |
| 眼是豆形 + 上眼睑细线 | 太灵、太动漫 | **实心黑圆角矩形**，低且间距大，无高光无睫毛 |
| 头发一丝丝描 + 灰色高光 | 丢掉涂鸦感 | **一整块黑** + 白色蜡笔划痕 |
| 填色内缩 1–3px、接近平涂 | 太干净 | 斜排线，**内缩 3–5px** 露白，压力不均 |
| 人物占宽 65–70% | 像贴纸小卡 | **75–80%** |
| 只写文字描述 | 模型自动走「好看」路线 | **必须挂风格样张当第 2 张参考图** |

## 风格一句话

**白纸上两个方脸大头人，黑蜡笔线抖着画了两遍，颜色是斜着排线涂不满的，右下角有 `sdldyh`。**

关键不是「可爱」，是「糙」。判断标准只有一条：**把成品和用户样张并排缩小看，小图分不出来才算过。**

输入统一为 `references/originals/original-photo-car.jpg`（图 1）+ `references/style-ref-sample.jpg`（图 2）。

| 09 | `09-full-body.jpg` | 4:5 坐姿 | 928×1152 | 4.5 | 4.5 | 坐姿成立，但比例偏成熟，头不够大 |
| 10 | `10-heart-hands.jpg` | 4:5 比心 | 928×1152 | 4 | 4.5 | 比心手只有 3 指，刚好；女生衣色被沁成米色 |

**四条结论**

1. **风格样张不能省**：v1 只有文字，出图自动「美化」；v2 挂上样张后，同一句 prompt 的线、色、脸型全部变糙。
2. **写「两遍线」是性价比最高的一句**：`every contour drawn TWICE` 比任何「rough / hand-drawn」都有效。
3. **脸型决定像不像**：`wide flat square-ish face, blunt jaw` 一出，相似度立刻上一个档；写 `chibi / cute` 就会回到圆脸。
4. **手要借原图**：托脸、放头顶这种「大块手」几乎不崩；凭空加的比心、牵手才容易多指。

## 上手

```sh
# 只需要 Pillow
python3 -m venv .venv && .venv/bin/pip install Pillow

.venv/bin/python scripts/sheet.py out-v2   # → examples/contact-sheet-v2.jpg
.venv/bin/python scripts/sheet.py          # → examples/contact-sheet.jpg（v1）
```

生成时：把照片放第 1、`references/style-ref-sample.jpg` 放第 2，提示词直接用 `references/prompts.md` 的公共块。

## 签名

固定 `sdldyh`，右下角、小、斜、细。模型写坏先重跑一次；连续两次坏就用 `prompts.md` 末尾的 Pillow 脚本叠字——这是这套流程里唯一允许的后期。
