# scribble-couple · 蜡笔涂鸦情侣头像（签名 sdldyh）v2

> 复刻用户发来的那版「抖音手绘情侣头像」：纯白纸、**两遍**抖断的黑蜡笔线、方宽脸、黑色圆角矩形眼、整块黑刘海、彩铅斜排线露白、每侧三四道腮红，右下角手写 `sdldyh`。
> 一个 `SKILL.md` + 风格拆解 + 可复制提示词 + **10 张用用户原片复刻的成品**，不依赖任何第三方服务。

## 这一版为什么重做

v1 交付后用户的判断是：**「你复刻的一点都不像，没我上传的好看。」**

把 v1 成品和用户样张并排缩小看，问题一眼就出来了：

| v1 做错的事 | 后果 | v2 的修法 |
|---|---|---|
| 单层、等宽、顺滑的线 | 像矢量贴纸 | **每条轮廓画两遍**，抖、断、末端出头 5–10px |
| 圆脸 + 尖下巴 | 变成「精致二次元」 | **宽、平、略方**，下颌几乎垂直，下巴钝平 |
| 眼是豆形 + 上眼睑细线 | 太灵、太动漫 | **实心黑圆角矩形**，低且间距大，无高光无睫毛 |
| 头发一丝丝描 + 灰色高光 | 丢掉涂鸦感 | **一整块黑** + 白色蜡笔划痕 |
| 填色内缩 1–3px、接近平涂 | 太干净 | 斜排线，**内缩 3–5px** 露白，压力不均 |
| 人物占宽 65–70% | 像贴纸小卡 | **75–80%** |
| 只写文字描述 | 模型自动走「好看」路线 | **必须挂风格样张当第 2 张参考图** |

## 风格一句话

**白纸上两个方脸大头人，黑蜡笔线抖着画了两遍，颜色是斜着排线涂不满的，右下角有 `sdldyh`。**

关键不是「可爱」，是「糙」。判断标准只有一条：**把成品和用户样张并排缩小看，小图分不出来才算过。**

**四条结论**

1. **风格样张不能省**：v1 只有文字，出图自动「美化」；v2 挂上样张后，同一句 prompt 的线、色、脸型全部变糙。
2. **写「两遍线」是性价比最高的一句**：`every contour drawn TWICE` 比任何「rough / hand-drawn」都有效。
3. **脸型决定像不像**：`wide flat square-ish face, blunt jaw` 一出，相似度立刻上一个档；写 `chibi / cute` 就会回到圆脸。
4. **手要借原图**：托脸、放头顶这种「大块手」几乎不崩；凭空加的比心、牵手才容易多指。

## v4：五对 × 两版（2026-11-03）

## v5：对齐「上一版」的完成度（2026-11-03）

用户反馈：**新版两版都不如上一版好看**。诊断结论（也是本轮最重要的经验）：

| 我在 v4 里做的 | 为什么变丑 |
|---|---|
| 把「软彩铅」= 线变细、大部分闭合 | 结构线没了 → 变成通用可爱插画 |
| 皮肤「暖蜜桃铺满」 | 丢掉纸白露白 → 手绘感消失 |
| 头发从「整块黑 + 白划痕」改「浅棕细线」 | 视觉重量掉了，脸变轻飘 |
| 没写「保持结构」 | 模型把 soft 理解成「所有东西都弱一点」 |

修法有两步，都很关键：

1. **把上一版当第三张参考图**：`images=[原片, 原画, 上一版]`，提示词里写 `match its density, contrast and finish — same amount of solid black, same bare white paper, same head size`。
2. **重新定义两版**：版本① 黑更多、皮肤更白；版本② 只软颜色、不软线。口诀——**「软」只允许软在颜色，不允许软在线和黑**。

产出：`examples/out-v5/` 10 张（5 对 × 2 版）。对照总表 `examples/compare-v5-four-columns.jpg`：**原片 | 上一版（蓝框）| 新版① 重蜡笔 | 新版② 软彩铅**。

## v6：先把原画参考切干净，再谈提示词（2026-11-03）

用户反馈：**「原来生成的（参考）你没有了，导致偏差很大」**。

结论很直接——这一轮的问题不在提示词，在**参考图本身**：

| 病 | 具体表现 | 后果 |
|---|---|---|
| A 的原画参考带「已滑屏」气泡 | 气泡压住右侧人物肩膀和下半张脸 | 模型把气泡当画面元素，人物位置整体右移 |
| C 的原画参考带深灰截图边 | 左右两侧各有 20–40px 灰边 | 生图把灰边读成「纸的边界」，画面被压扁、留白变灰 |
| 旧 `artworks/artwork-*.jpg` 部分是被缩略图裁过的 | 头部被切、构图比例失真 | 头部大小和取景一路偏 |

### 修法：新建 `references/artworks/clean/`

从**无遮挡的那张截图**重新裁，只留白纸上的画：

| 对 | 无遮挡来源 | 裁切框（1080×2400） | 输出 |
|---|---|---|---|
| A | `shot-0330713`（这张没气泡） | (120,300)-(930,1140) | 810×840 |
| C | `shot-0345802` | (140,345)-(1035,1215) | 895×870 |
| B / D / E | 原图无遮挡 | — | 直接转存 |

裁完全部 `read_file` 放大目检，四条清单：无气泡、四边无灰边、两张脸都完整、白纸边缘没有 UI 残角。

### 生成方式：三图参考（缺一不可）

```
images = [originals/original-X.jpg,          # 图 1 真实原片
          artworks/clean/artwork-X.jpg,      # 图 2 干净原画 = 风格基准

```

提示词第一段就点名：`Image 2 = the artist's ORIGINAL drawing … uncropped and unobstructed — ground truth for the style`，
随后每条 `Style facts to copy from image 2` 单独列（线两遍 / 发块整 / 皮肤留白 / 黑方块眼 / 腮红位置 / 服装处理 / 裁到胸口）。

## v7：口径修正——要复刻的是第二列那张原画（2026-11-03）

用户第三次指正，也是真正的口径：

> 「我要你复刻五列中的第二列的原画……你肯定是复刻原画，复刻两版呀。」

前六轮我一直做的是「**用原画当风格，照原片重画**」，所以永远差一截——
因为原片的姿势、取景、道具本来就和原画不同，重画得越认真，离原画越远。

**改法**：把原画本身当 target，不再当 reference。

```
images = [artworks/clean/artwork-X.jpg,   # 图 1 = 原画 = 目标，要 1:1 复刻
          originals/original-X.jpg]       # 图 2 = 原片 = 只核对细节
```

提示词开头写 `IMAGE 1 IS THE TARGET, NOT A REFERENCE`，再逐项列
`Exact content to reproduce:`（左人 / 右人 / 小道具 / 背景 / 签名），并明确
`Never change the composition of image 1 to match the photo`。

**两版**：
- **① 重蜡笔**＝忠实复刻，什么都不改；
- **② 软彩铅**＝同一张画的更细彩铅收尾，只改颜色过渡与排线疏密，构图/姿势/头身比/黑线粗细/留白全部不动。

## v10：中国情侣十对 + 笔触标定（2026-11-03）

上一轮 v8 的十对「差别还是太大」。量了一下才发现问题不在黑的比例：

所以这一轮改的不是「更多黑」，而是「**笔更粗、块更整**」。

- 新增 `CRAYON HAND` 段（已写进 `SKILL.md`）：线粗约一个眼睛宽、短而钝、两遍双勾；
  头发是一整块不透明黑 + 3–4 道白划痕；衣服 8–15 笔粗斜排线、中间露白；
  整张约 1/3 是黑或颜色，一半是白纸。
- 判断标准：**缩小到 25% 还看得出「胖黑线 + 大白块」就对**，变成灰糊糊一片细线就是错。

## v10（2026-11）第三列到底是怎么来的

用户问「之前第三列不会是复刻的第二列吧」——**是**。第六轮第三列 = 拿第二列原画当 target 的 1:1 复刻，
所以它像；这不构成「只给照片也能画成那样」的证据。v10 把四条路线并排测了五对：

- `tests/v10/review-sheet.jpg`：原片 | 原画（目标）| 第六轮第三列 | 只用照片+风格锚 | 照片+本对原画（第六轮提示词）
- `tests/v10/sheet-two-stage.jpg`：原片 | 原画 | 只用照片出的草图 | 草图再复刻一遍加粗

结果：复用第六轮提示词（原画在场）→ 五对全部回到第三列水平；只用照片 → 线细、脸圆、眼大；
二次复刻 → 变糙但会改道具。**第 7、8 两轮已被用户删除，不要再当交付。**
