# 风格拆解：把「那张蜡笔涂鸦情侣头像」拆成可执行的参数（v2）

拆解依据：用户提供的 5 张抖音截图（原作者账号水印 `danxiaogui`）。裁出的干净样张见 `style-ref-sample.jpg`，**它每次出图都要作为第 2 张参考图挂上**。

> 说明：这只是**风格要素**的工程化描述，用于生成同风格的新作品，不复制任何一张原画。

版本记录：v1 的拆解（圆脸、1:2.2、单线、色内缩 1–3px）在本轮被实测证伪——出图干净得像精致二次元，用户判定「一点都不像」。下面所有带 ⚠️ 的条目都是 v1 的错，已按实测改写。

## 1. 画布与构图

| 项 | 实测值 |
|---|---|
| 比例 | 竖版 4:5 为主，方头像用 1:1，特写可用 3:4 |
| 底色 | 纯白 `#FFFFFF`，无纹理、无投影、无边框 |
| 主体占比 | 两人合计占画面**宽度 75–80%**（v1 写 65–70%，实际出图人太小、太像贴纸） |
| 头顶留白 | ≈ 6–10%，只够放爱心和星星 |
| 裁切 | 到胸口 / 上臂；坐姿版裁到膝上；不画腿 |

## 2. 线（第一决定因素）

- 颜色 `#171717`，不是纯黑也不是灰。
- 粗细：外轮廓 4–7px，内部结构 2–3px（按 1000px 画幅），**同一根线里粗细本身在变**。
- ⚠️ **每条轮廓画两遍**。这是最容易被忽略、也最出效果的一条：第二遍偏移 2–4px，末端不封口。v1 只写了一层线，出图立刻变成矢量贴纸。
- 抖、断、末端出头 5–10px；拐角留 3–5px 缺口。
- 头发：**一整块黑**，块内用白色蜡笔划痕透出纸色（不是用灰线画高光）；轮廓外 5–10 根乱飞线，长短不一。
- 刘海：**压成一整块黑**，只在下缘切几刀分出几缕；v1 画成一丝丝，直接毁掉相似度。
- 服装：只留 1–2 条结构线（领口、袖口），其余交给排线色块。

## 3. 色（第二决定因素）

- 媒介：彩铅 / 蜡笔，颗粒可见，压力不均（有深有浅）。
- 覆盖方式：**斜向排线（约 45°）**，线之间留白纸缝；**色块内缩线内 3–5px**，故意错位。
- 不叠第二层、不做渐变、不画投影、不画阴影（v1 的「光滑填色」是致命伤）。
- 白衣服 = 基本留纸，只画轮廓 + 几笔浅影。
- 典型色板：

| 用途 | 近似色 | 备注 |
|---|---|---|
| 黑发 / 线 | `#171717` | 块内白划痕 |
| 皮肤 | `#F6C9AC` 斜排线 | 空隙露白，不是平涂 |
| 腮红 | `#E8604C` | 3–4 道短线 |
| 红心 | `#E5484D` | 一颗 |
| 黄星 | `#F5C542` | 1–3 颗 |
| 深蓝（男方 POLO / 卫衣） | `#2F4470` | 衣褶处断开 |
| 牛仔蓝 | `#3F5C86` | — |
| 军绿 / 卡其 | `#9A9470` | — |

## 4. 脸：只有五个零件，但比例很硬

| 零件 | 画法 |
|---|---|
| 脸型 | ⚠️ **宽、平、略方**：颧骨到下颌几乎垂直，下巴钝平（不是圆点下巴）。脸宽 ≈ 脸高 × 0.85。头身比 ≈ 1 : 1.6，肩极窄 |
| 眼 | ⚠️ **实心黑圆角矩形**（竖着的小胶囊），位置**偏低、间距大**（两眼间距 ≈ 一只眼的宽 × 1.5）；无眼白、无高光、无睫毛、无瞳孔；上眼睑另起一条更粗的短线压在眼睛上方 |
| 眉 | 粗、短、平，几乎贴着上眼睑 |
| 鼻 | 一个点（或 3px 小 v），没有鼻梁 |
| 嘴 | 小张口笑，内里浅粉 / 纸白；或一条短上弧 |
| 腮红 | ⚠️ 每侧 **3–4 道**短斜排线，间距 4–6px，压在脸颊外侧，是「线」不是「雾」 |

## 5. 点缀系统（少而固定）

- 小红心：1 颗，飘在两人之间或头侧，边缘毛。
- 黄色星星：1–3 颗，四角星，实心。
- 短感叹号：0–2 个，只在动作夸张时加。
- 不加任何其他东西：不要花、云、文字、贴纸边框、拍立得白边。

## 6. 签名

- 内容：原作者 `danxiaogui`；本技能固定 **`sdldyh`**。
- 位置：右下角，距右 / 下边 6–8%。
- 大小：高度 ≈ 画面 2–3%（1000px 宽 → 20–30px）。
- 姿态：手写连笔，右上倾斜 8–12°，细，末尾甩一下。不加下划线、不加框、不加日期。

## 7. 与原图的关系

保留：

1. **发型轮廓**（直/卷、长/短、刘海形状、绑法）——辨认第一锚点。
2. **服装主色块**（1–2 个）+ 一个配饰（墨镜、串珠手链、手表、帽子）。
3. **相对位置、身高差、头部倾斜方向、手势关系**（手托脸 / 手放头顶 / 比心）。

放弃：

- 五官细节、皮肤质感、背景、光线方向、真实比例、表情微差。
- 画面里的文字、logo、水印一律不画。

## 8. 一句话检验

1. 「这两个人是一对吗？」——不是，构图错了。
2. 「这是拿蜡笔随手涂的吗？」——不是，线或色太干净了（回查是否两遍线、是否露白、刘海是否整块）。
3. 「远看像不像用户发的那张？」——把成品与样张并排放小图看。**小图不像 = 失败**，这就是 v1 翻车的判定方式。

## 9. 原画 ↔ 原片 一一对应表（v3 修正）

一份截图 = 一对情侣的原画 + 一对情侣的原片，**不是同一对**。做之前先对齐：

| 对 | 原片 | 原画 | 手感 |
|---|---|---|---|
| A | `originals/original-A.jpg` | `artworks/artwork-A.jpg` | 重蜡笔 |
| B | `originals/original-B.jpg` | `artworks/artwork-B.jpg` | 重蜡笔（条纹要画断） |
| C | `originals/original-C.jpg` | `artworks/artwork-C.jpg` | 重蜡笔 |
| D | `originals/original-D.jpg` | `artworks/artwork-D.jpg` | 软彩铅 |

对齐自检四条：发型、衣服（条纹/图案）、配饰、手势。四条全中才是同一对。

**两种手感的差别**：A/B/C 是「黑块头发 + 纸白皮肤 + 露白排线 + 粗黑两遍线」；D 是「软铅笔细线 + 暖蜜桃铺满 + 阴影侧加深一档 + 背景留几笔灰棕暗示」。同一批只能用一种。
