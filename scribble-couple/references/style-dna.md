# 风格拆解：把「那张手绘情侣头像」拆成可执行的参数

拆解依据：用户提供的 5 张抖音截图（原作者账号水印 `danxiaogui`）。裁出的干净样张见 `style-ref-sample.jpg`，本仓库所有复刻测试都以它为风格参考图。

> 说明：这只是**风格要素**的工程化描述，用于生成同风格的新作品，不复制任何一张原画。

## 1. 画布与构图

| 项 | 实测值 |
|---|---|
| 比例 | 竖版，接近 4:5（截图里画心区域 1080×860 左右，裁掉 UI 后约 4:5） |
| 底色 | 纯白 `#FFFFFF`，无纹理、无投影、无边框 |
| 主体占比 | 两人头部合计宽度 ≈ 画面宽 65–70%；头顶留白 ≈ 8–12% |
| 裁切 | 到胸口 / 上臂，不画腿；全身版才画到脚 |
| 位置 | 两人头部略偏上，重心在画面中上 1/3 |

## 2. 线（决定像不像的关键）

- 颜色：接近纯黑 `#141414`，不是灰、不是棕。
- 粗细：外轮廓 4–6px，内部结构线 2–3px（按 1000px 画幅）。
- 质感：**抖、断、复线**。同一条边常有 2 条线并行，末端出小杈；拐角处经常不闭合，露出 2–4px 白缝。
- 头发：不描每一根，用**实心黑块 + 5～10 根乱飞线**；发梢用短促的断线收尾。
- 服装：只画 1–2 条结构线（领口、袖口、口袋），其余交给色块。

## 3. 色（决定「手绘感」的关键）

- 媒介：彩铅 / 蜡笔 / 软粉笔，颗粒明显。
- 覆盖：**涂不满**。色块内可见白色纸缝与排线方向；色块边缘比线内缩 1–3px，故意错位。
- 方向：一律斜向排线（约 45°），同一色块内方向基本一致，不叠第二层。
- 阴影：几乎不画。顶多在脖子、手臂交界压一道更深的同色斜线。
- 典型色板：

| 用途 | 近似色 |
|---|---|
| 皮肤 | 蜜桃 `#FFE1CF`（阴影 `#F3C4AC`） |
| 腮红 | 珊瑚粉 `#F0908C` |
| 黑发 | `#1B1B1B` + 少量 `#3A3A3A` 飞线 |
| 棕发 | `#6B4A34` / `#8A6242` |
| 红衣 / 红心 | `#D9433F` |
| 黄衣 / 星星 | `#F5C242` |
| 牛仔蓝 | `#5B7FA6` |
| 军绿衬衫 | `#9A9470` |

## 4. 脸：只有五个零件

| 零件 | 画法 |
|---|---|
| 眼 | 实心黑，豆形或圆角方，**无高光**；上眼睑再压一条更粗的黑线，形成「半眯」的松弛感 |
| 眉 | 粗、短、平，略下垂；离眼很近 |
| 鼻 | 一个点，或一个 3px 的小 v；没有鼻梁 |
| 嘴 | 小张口笑，内里一抹淡粉；或一条向上弧线 + 嘴角一点 |
| 腮红 | 每侧 **3 条**短斜线，间距 4–6px，压在脸颊上（不是雾状） |

脸型：宽而扁的圆，下巴短、几乎平；脸颊两侧略外扩。头身比 ≈ 1 : 2.2（头极大，肩极窄）。

## 5. 点缀系统（少而固定）

- 小红心：1 个，飘在两人之间或头侧，5–8mm 大小，边缘毛。
- 黄色星星：1–3 个，四角星，实心。
- 情绪线：2–4 条短放射线（在头侧或手边），只在动作夸张时加。
- 没有任何其他装饰：不要花、不要云、不要文字、不要贴纸边框。

## 6. 签名

- 内容：原作者是 `danxiaogui`；本技能固定为 **`sdldyh`**。
- 位置：右下角，距右 / 下边约 6–8%。
- 大小：高度 ≈ 画面 2–3%（1000px 宽 → 20–30px）。
- 姿态：手写连笔、整体向右上倾斜 8–12°，笔画细，末尾甩一个小尾巴。
- 不加下划线、不加框、不加日期。

## 7. 与原图的关系

保留：

1. 两人的**发型轮廓**（直/卷、长/短、刘海形状）——这是辨认的第一锚点。
2. **服装主色块**（1–2 个）与一个配饰/道具。
3. **相对位置与身高差**、头部倾斜方向、手部动作关系。

放弃：

- 五官细节、皮肤质感、背景、光线方向、真实比例、表情微差。
- 画面里的文字、logo、招牌一律不画。

## 8. 一句话检验

把成品给不了解原图的人看，然后问两个问题：

1. 「这两个人是一对吗？」——不是，就是构图错了。
2. 「这是用蜡笔画的吗？」——不是，就是线或色太干净了。
