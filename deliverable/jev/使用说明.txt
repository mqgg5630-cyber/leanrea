JevChat + 常驻监控  使用说明
==================================================
部署位置：E:\0apps\jev-chat-windows
（不能放 E:\0github —— git-sync-hub 每次轮询会清空那里除 .git-sync / results 之外的东西）

一、日常怎么用
--------------------------------------------------
1. 打开微信（E:\新建文件夹\Weixin\Weixin.exe）或 QQ，把要聊的会话点开，
   窗口**不要最小化**（被别的窗口盖住没关系，最小化就截不到画面）。
2. 程序会自己在登录时启动（计划任务 jev-chat-monitor）。
   没启动就双击：E:\0apps\jev-chat-windows\monitor\start_monitor.ps1
   或者：右键开始菜单 → 运行 → powershell -File "E:\0apps\jev-chat-windows\monitor\start_monitor.ps1"
3. 悬浮窗出现后，对方来消息 → 程序判断 + 给 3 条候选（需要填 API key 才会自己出候选）。
   **发送永远手动**，程序只负责把字填进输入框。

二、没有 API key 也能用
--------------------------------------------------
没有 JEV_API_KEY / LLM_API_KEY 时：程序不自己给候选，但**照样把每条新消息记录下来**，
记录在 E:\0apps\jev-chat-windows\logs\events.jsonl，同时生成可读的
E:\0apps\jev-chat-windows\logs\digest-年月日.md。

要让 AI 分析这些记录：回到 Arena 那个对话里说一句「拉一下最新聊天记录」，
agent 会通过 git-sync-hub 拉取快照、给出分析，结果写到：
  E:\0github\results\leanrea-4d729933-leanrea\jev-monitor\analysis-*.md
（这个目录是自动镜像的，直接打开看就行。）

三、状态与排障
--------------------------------------------------
一键体检：
  powershell -NoProfile -ExecutionPolicy Bypass -File E:\0apps\jev-chat-windows\tools\status.ps1
关键日志：
  logs\install.log      部署过程
  logs\pip.log          依赖安装
  logs\monitor.log      启动/同步
  logs\app_err.log      程序报错
  logs\events.jsonl     聊天记录（一行一条 JSON）

常见问题
  · 提示「采集停了（聊天窗口关了？）」→ 微信/QQ 主窗口被关或最小化了
  · 提示「消息区认不出来（窗口太小？）」→ 把窗口拉大；QQ 的布局需要校准
  · 悬浮窗不出现 → 看 app_err.log，通常是缺依赖，重跑 tools\wheelhouse.ps1 或 pip_worker.ps1

四、隐私
--------------------------------------------------
· 只截自己屏幕上的聊天窗口，截图**不落盘**，只在内存里做 OCR
· 记录的是 OCR 出来的文字，存在本机
· 默认**不自动上传**任何东西；只有你在 Arena 里让我拉取时，才会通过 git 同步一次
· 想彻底停掉：任务计划里禁用 jev-chat-monitor，然后删掉 E:\0apps\jev-chat-windows\logs\*.jsonl
