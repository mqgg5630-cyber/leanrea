## 为什么挑这条

- **场景最日常**：一起旅行、一起运动、一起早睡——几乎每对情侣都许过这类愿，读者一眼代入；
- **判断句本身就是金句**：「大承诺提供想象，小承诺提供证据」——可直接上封面；
- **和《毁掉关系的八种做法》同构**：先点破一个大家都中招的坏习惯（说到做不到），再给一个马上能做的小动作（两周内可验证的一件事），情绪曲线是「轻微刺痛 → 被理解 → 能做到」；
- **门槛低**：条目自身标注 成本 0 / 时间少 / 难度低 / 收益大 / 场景日常 / 依据 C，适合做成「今天就能用」的轻内容。

## 原文摘录（引用）

> **情况**：你们常说要一起旅行、一起运动、一起早睡，最后都没实现，彼此越来越不信对方的话。
> **判断**：大承诺提供想象，小承诺提供证据。先做一件两周内能验证的事，比再许一个愿更有用。

### 正文（约 340 字，≤1000 字上限）
```
「下次一定。」
「等忙完这阵我们就去旅行。」
说了太多次以后，他自己也发现：说完这句话，两个人都不太信了。

书里有个判断我记到现在：
大承诺提供想象，小承诺提供证据。
先做一件两周内能验证的事，比再许一个愿更有用。——《引导型恋人指南》3.7

所以最近我们改了三件事：
1️⃣ 许愿前先问自己：两周内能兑现吗？不能就先不说
2️⃣ 一次只挑一件，做到了不邀功（「你看我说到做到」一出口就变味了）
3️⃣ 没做到不辩护，只说下一件什么时候补

上周就一件小事：周三一起吃晚饭，我订位。
做到了。比「明年去北海道」管用多了。

不是不许愿了，是先把「说到做到」攒回来。
你最近一次说到没做到的是什么？评论区聊聊👇
```
