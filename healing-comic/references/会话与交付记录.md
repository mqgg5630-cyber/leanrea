   `google_drive__download_file` 拉下来后用 `pypdf` 抽全文，**不要**用 `read_file_text`（长 PDF 会丢中间章节）。
2. **选章节不撞车**：批A=第 11 章，批B=第 12–13 章，批C=第 8 章；
   另一套 AI 已做第 1–10 章各 1 张（`引导型恋人_文案拆解版_2026-11-02`）+ 第 01 批 10 张。
   下一批建议第 6 章（提问、选择、留白）或第 9 章（治愈）。
3. **写文案**：照 `references/文案拆解方法.md`——先列源文映射表，再写「标签 / 点题句 / 触句 / 引导句」。
4. **出图**：一次最多 10 张；每次挂 `原图01.png` + `原图04.png`；提示词用 `references/anime2-批C-生图提示词.md` 的公共块。
5. **合成**：`python3 scripts/compose.py spec-C.json --font … --font-medium … --art-root . --outdir pages-C --layout xhs-orig --html --contact-sheet`
   （gate 不过就改文案，别改 gate）。
6. **上传**：新批次 = 新文件夹（`批D_xxx/图片` + `批D_xxx/文案与提示词`），**绝不覆盖别人的产出**。
7. **提交**：`git add -A && git commit && git push origin arena/7c8f4dad-leanrea`。
