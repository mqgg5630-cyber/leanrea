# GitHub 上「睡前故事 / 一张图情侣头像 / 聊天背景图」Skills 调研

调研时间：2026-11-03。方法：web 搜索多组中英文关键词 + `gh api repos/...` 核对 star 数与最近推送时间（star 数为当日 GitHub API 返回值），不是只看搜索摘要。

## 结论先说

**三类都有，但形态不同：**

1. **睡前故事**：生态最成熟，中文首选 `anbeime/skill` 里的 `bedtime-story`（仓库 ★9075），一条命令装好。
2. **一张图片 → 情侣头像**：`wzj52501/aesthetic-atelier` 里的 `matching-couple-avatar` 子技能就是干这个的——**只给一张头像，它只画缺失的另一半**，原图不动、像素级锁定画风，和"一张图制情侣头像"的描述完全吻合。老牌 `CoupleGenerator`（★457）反而要两张照片，不符合你的场景。
3. **聊天背景图**：没有专门的"聊天背景生成"skill；分两条路——① **AI 出图**：用通用生图 skill（如 `chemny/ai-image-generator`，内置「手机壁纸 9:16 1080×1920」尺寸规则）直接生成竖屏背景；② **把图设成聊天背景**：DSH 插件 `dsh-chat-background` / `dsh-chat-wallpaper`（后者还自动保证文字对比度 ≥4.5:1）。

## 安装速查（skills.sh / npx skills）

```sh
# 睡前故事（中文）
npx skills add https://github.com/anbeime/skill --skill bedtime-story

# 一张图 → 情侣头像（clone 后按 SKILL.md 走）
git clone https://github.com/wzj52501/aesthetic-atelier.git

# 通用生图（聊天背景 9:16 就靠它）
npx skills add chemny/ai-image-generator
```

> 说明：`npx skills` 是 Vercel Labs 的 skills CLI（github.com/vercel-labs/skills），本质是从 GitHub 下载 SKILL.md 到各 agent 的 skills 目录；装完若不生效，新开一轮对话再试。
