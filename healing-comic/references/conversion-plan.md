## 一、现状的问题（为什么「字再多也不像小红书漫画」）

| 现状 | 问题 |
|---|---|
| 20 张 **4:3 横版**文字卡 | 小红书信息流是 3:4 竖版，横版被裁、占屏小；20 张还超过单篇 18 图上限 |
| 每页是「目录 / 干货 / 章节速览」 | 是**资料**，不是**故事**；没有角色、没有动作、没有情绪转折 |
| 一张卡塞 5–10 行字 | 缩略图里一个字都读不出，治愈感被信息密度吃掉 |
| 正文 760 字 + 话题标签 | 文案其实已经写得很好，但和画面是两套语言，图只是「配图」 |
| 原文每条 10 个字段（情况/判断/第一句/两种回应/接着做/做对了/红线/依据/来源/相关） | 这是**查询手册**的结构，硬塞进漫画只会变成带插画的表格 |

**关键判断：不是给现有的 20 张卡换个画风，而是砍掉 14 张，重做成 6–9 页竖版漫画。** 原文不动，仍作为「想查具体场景时」的落地页/长文版；漫画只负责让人「想点进来、想收藏、想 @ 那个人」。

## 二、三处要改的地方

### 1. 内容：从「104 条」到「一句话」
一次只讲 **4 条底线**（目录 p.3，全书的收敛点），因为它天然是清单式、天然是「毁掉关系的做法」的反面，和你给的那条《毁掉关系的八种做法》同一个钩子。

| 页 | 源文 | 压成一句能说出口的话 |
|---|---|---|
| 封面 | 导言 | 「引导不是当爹当妈，是把选择权还回去。」 |
| ① 同意可撤回 | 四条底线 1；2.6 第一句：「你想一个人待着可以。我们定一下下次见面：周日晚上吃饭，还是下周三？你选一个…」 | 「那我不加安排，你有空再告诉我。」 |
| ② 不改造人格 | 四条底线 2 | 「我不改你，我只说这件事让我有点难受。」 |
| ③ 不代替专业帮助 | 四条底线 3；13.8 第一句：「我想找个人帮我们把循环看清楚。不是谁有病，是我们两个在原地打转。」 | 「我们一起找人聊聊，不是谁有病。」 |
| ④ 不监控不试探 | 四条底线 4；第 11 章 | 「你的手机，我不看。」 |
| 尾页 | 导言 + 13 章 | 「两个人都站在自己的位置上，既能靠近，也有退路。」 |

> 原书里 A–D 证据等级、来源编号、红线长句**一律不进画面**，放进正文配文的「完整版在这里」一句里，保留原书的严谨但不破坏画面。

### 2. 视觉：从「大字卡」到「两只熊 + 留白」

| 项 | 现在 | 改成 |
|---|---|---|
| 比例 | 4:3 横版 | **1080×1440 竖版 3:4** |
| 页数 | 20 张 | **6–9 张**（样张做了 6 张） |
| 主角 | 无 | 一二布布风：白熊猫（黑眼罩 + 黑领结）+ 奶茶棕熊，细黑描边平涂；原创版在 `examples/art-original/` |
| 每页信息 | 5–10 行 | 顶部标题 ≤12 字 + 一句台词 ≤18 字 + 一行金句 ≤24 字 |
| 背景 | 色块 / 网格 | 奶油白 #FFF8EE，最多两件小道具（杯子、盆栽、手机） |
| 分格 | 无 / 多栏 | **一页一格**，不画 2×2 四格，角色才不会漂 |
| 中文字 | 直接排在图里 | **生图阶段零文字**，全部由 `scripts/compose.py` 后期合成 |

角色必须原创：一二布布是黄小 B 的受保护 IP（2018），只借「两只圆滚滚动物 + 一句对话」的类型语法，见 `SKILL.md`。

### 3. 文案：从「发布长文」到「一句钩子 + 短配文」

建议标题（≤20 字，沿用你文案包里已经验证过的角度）：
- `真正的引导型恋人，从来不是当爹当妈`（17 字，主推）
- `把选择权还给 TA，再在旁边站得稳一点`（18 字）
- `毁掉关系的 4 件事，第 2 件最容易犯`（17 字，对齐你给的那条笔记的钩子）

配文结构（约 300–400 字，≤1000 字）：
1. 一句反差开场：「以前我以为引导 = 替他兜底一切。」
2. 一句书里的判断标准：「如果一句话让对方更怕你、更依赖你、更没得选，那它不叫引导。」
3. 4 条底线用 4 行短句列完（就是图里的 4 句台词）。
4. 一句「完整 13 章 104 个具体场景 / 第一句原话在书里」的落地指引。
5. 免责 + 署名 + 话题（`#引导型恋人 #亲密关系 #一二布布 #边界感 #舒服的关系 #回避型依恋`）。
6. 置顶评论沿用你文案包里那份「四种最快用法」，把想查条目的人接住。
