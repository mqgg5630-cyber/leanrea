# 旁白说明

视频里的两声「一二」「布布」是 AI 合成的中文旁白（试听时选定的两个音色），
台词就是每页气泡里那一句，延迟 0.6 秒进入，配音用 ffmpeg 混流，视频流未重新编码。

| 文件 | 台词 | 说话人 |
|---|---|---|
| 01-封面.mp3 | 爱TA，但不弄丢自己。 | 一二 |
| 02-不查手机.mp3 | 你的手机，我不看。 | 一二 |
| 03-先问再说.mp3 | 先听你说，还是我说个建议？ | 一二 |
| 04-互相照顾.mp3 | 你也可以被照顾。 | 一二 |
| 05-先接住情绪.mp3 | 我先陪你一会儿，不急着讲道理。 | 布布 |
| 06-并肩不代替.mp3 | 我们一起弄，你管一半。 | 一二 |
| 07-结尾.mp3 | 两个人都站在自己的位置上，就很好。 | 一二 |

- `视频/` 里是**已混旁白**的成品（7 段 + 1 段 44.6 秒全套合集）。
- `视频/无旁白版/` 是同规格的**无声版**，想自己配 BGM 或换成真人配音时用这个。
- 重新混流（自己换台词）：

```sh
ffmpeg -y -i 无旁白版/02-不查手机.mp4 -i 02-不查手机.mp3 \
  -filter_complex "[1:a]adelay=600:all=1,apad[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 128k -shortest out.mp4
```

- 注意 `apad`：没有它，`-shortest` 会把视频截到音频长度（画面只剩两三秒）。
- 音频是 AAC 单声道 44.1kHz；小红书发布时通常还会叠一层平台 BGM，音量别拉太高。
