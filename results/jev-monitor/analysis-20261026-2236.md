## 2. 判断

| 项 | 判断 |
|---|---|
| 字面 / 潜台词 | **潜台词**。不是陈述"你会很忙"，是"我怕你忙起来就把我放次要位置" |
| 真实意图 | 提前索取承诺（**confirm_you_care**），顺带试探你的反应 |
| 情绪 | 不安 + 撒娇，浓度中等；不是生气，但**正在等你接住** |
| 结构 | 先给糖（"我也想你啦"），再提担心 —— 典型的"软话开路、要求在后" |
| 风险 | **高**。你回的是日程（洗衣服）。在她那儿读作"我说了他在躲"，且会被记下来，下次吵架翻出来 |

## 3. 三条候选（按推荐排序）

**① 推荐**
> 不会的。忙归忙，每天睡前一定留半小时只给你。我现在去把衣服洗了，洗完就回来找你，等我。

接住情绪 → 给可验证的承诺（"睡前半小时"）→ 保留你手上的事，但变成"洗完就回来"。
不认错、不解释、也不把话题丢给她。

**②**
> 你是不是怕我忙起来就不理你了？我记着你这句话。以后真忙我也提前跟你说，不让你自己猜。

直接把她的担心命名出来。适合她再追问、或你想把话说透的时候。

**③**
> 那我把"陪你"也写进日程，跟洗衣服一样，必须做。

轻一点的版本，带点幽默，适合气氛轻松时。
